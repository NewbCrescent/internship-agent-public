The Jobs toolbar accepts **Posted within last (days)** (1–365), Apply age filter, and Clear age filter.
`?days=3` selects employer publications in the last 72 hours, independently of import time, combined with category and sort; filter changes reset pagination.
Unknown dates are excluded only while the age filter is active, with an excluded count.
Category counts reflect the active age window.
The cached list expires when its earliest included posting ages out, even without database writes.
