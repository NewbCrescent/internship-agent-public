**Candidate notices.**
The pass and daily digest share candidate hold delivery.
They show genuine questions, visible challenges, requested documents, manual field corrections and approval when candidate action can move a run forward.
A submit that the site definitively rejects with structured field errors can restore candidate action after approval is withdrawn.
An unmatched invalid field is a browser correction, while a missing emailed security code is manager-owned.
An approved run with no evidence of a submit click remains in manager form review.
Unknown or missing conflicting evidence keeps the investigation open.
Questions keep their original run indices.
The digest marks only the revisions it showed and keeps its last numbered mapping through summary-only updates.
Employer replies and submission summaries still appear.
A delivery guard serializes sends.
A crash after Discord or tmux accepts output can repeat a notice if its acknowledgement did not reach SQLite.
