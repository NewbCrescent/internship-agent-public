New deterministic analyses use scoring version 2: normalized technology coverage (70% when preferred capability requirements exist, otherwise 100%) and preferred skill/experience keyword coverage (30%, or 100% when no technologies exist).
There is no automatic 50-point baseline, unrelated evidence-count bonus, or unspecified-work-mode bonus.
Zero with no comparable extracted requirements is explicitly described as insufficient measurement.
Existing version-1 results are labeled legacy until refreshed.
Fit remains separate from legal, degree, graduation and other eligibility checks.
