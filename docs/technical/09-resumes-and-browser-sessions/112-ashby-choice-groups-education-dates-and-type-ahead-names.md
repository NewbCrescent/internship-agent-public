**Ashby choice groups, education dates, and type-ahead names (2026-11-28, Track 83).**
Ashby names each box of a multi-choice question by its own option ("ROS", "Git"), so a checkbox group's id is no longer its first box's name: a group with an element id keeps it, a group whose boxes share one name keeps that name, else it takes the group's `data-ia-control` tag (Track 82, see `111-ashby-checkbox-groups.md`), else `checkbox-group-<n>` (`collectControlsIn`, `packages/browser/src/handshake-executor.ts`).
The group and each box are tagged (`data-ia-checkbox-group`, `data-ia-checkbox-option`), and a group with neither an element id nor a shared name is found by its tag, or, after Ashby redraws the form and drops every tag, again by its label (one field with that label); the one named option is checked through its own label and must show as chosen within 2 s, else the field is reported unfilled.
Groups with an element id or a shared box name (Greenhouse's) keep their path.
A month or year list whose first option is "Month..." or "Year..." and which has no label of its own takes the date label of its closest ancestors holding only it and its partner list ("Start Date month"), prefixed "Education " inside Ashby's education history entry (an entry holding a `_systemfield_education_history` control).
The planner answers Ashby's "Education Start Date month/year" from the profile's education start month and "Education End Date month/year" from the run's graduation date, as it does Greenhouse's education dates (`educationDecision`, `packages/browser/src/autofill-planner.ts`).
Ashby's "Still Student?" box (`_systemfield_education_history-isCurrent`, or a "Still student?" / "Currently enrolled?" label) is ticked while the graduation date is still ahead, and is left to the usual rules after it.
When the form has that box, the graduation date is ahead, and the End Date year list has no option for the graduation year, the End Date month and year both stay empty instead of half-filled.
A type-ahead asked for the profile's two-letter state code types the state's name ("California", so "California, United States" is picked), except a "State Abbreviation" box, and a field-of-study type-ahead with read options types the one option naming the field's category ("Engineering - Computer Science / Software").
The Ashby markup beyond the stored ids and body text is modelled (`testing-harness/browser/fixtures/ashby-education-history.html`; the multi-choice group in `ashby-value-select.html` is derived from Ashby's public bundle), so the two Ashby bug files stay open until a live run confirms them.
