Generic form reading takes labels from aria-labelledby first; an upload labelled only "Attach" takes its upload group's label ("Resume/CV", "Cover Letter"); each field is located by its own id before its label, so two "Attach" uploads never hit the same input; react-select lists (Greenhouse's new boards) are one select whose options are read by opening the list and pressing Escape (nothing is saved), and their hidden required inputs are not controls; a fieldset of checkboxes, or checkboxes sharing a name, is one question answered with one option (a "How did you hear about us?" group from the saved `how_heard` rule); radios sharing a name are one choice question (its label from the fieldset legend, the radiogroup's label, or the question text near the first radio; its options from each radio's label), answered by checking the radio whose label equals the chosen option, and a known answer is never typed into a radio, checkbox, list, or upload (the planner pauses with "… is a choice"; the executor refuses with "it is a choice, not a text box"); `aria-required` and a trailing required marker mark required fields.
Label text skips nested controls, live regions, status, listbox, and option widgets, and hidden elements, so Lever's "Current location ✱No location found…Loading" reads "Current location"; a label that wraps the whole question uses its own label element (Lever's `.application-label`); a control with no label of its own (Ashby's "Start typing..." box, Lever's custom questions) takes the question text near it (the closest legend, label, heading, or label/question/title element, or an element whose class holds "FormLabel" (case-sensitive: Dover's sibling `styles__FormLabel-…` question div), in up to six ancestors that hold no other question), with placeholder and name as the last resort.
An option's own label (a label holding exactly one radio or checkbox, such as MUI's "Yes" option) and text inside an aria-hidden element are never a question's label.
An upload with no label of its own looks for a nearby label (FormLabel included) in up to five ancestors and stops at the first that holds another question's control, so Dover's Resume drop zone reads "Resume", never a neighbouring radio's "Yes".
A drop zone whose `role="button"` box says "autofill" (Dover's "Autofill from resume") parses a resume into the form and is not a question, like Ashby's.

Every label source drops invisible characters (zero-width space and joiners, direction marks, soft hyphen, variation selectors, the byte-order mark: `INVISIBLE_CHARACTERS` in `form-recognition.ts`, copied into the in-page collector), so Dover's notched-outline legend that holds only U+200B is skipped like an empty one; a source that is a bare UUID is empty, and a name holding a UUID (Dover's custom questions) never labels a control: such a control takes its FormLabel question text, and with no other source it is "Unlabeled … control N".
Buttons, button and reset inputs, and controls with a button, link, menu item, or tab role are never fields, an unknown-kind control labelled only with an action word ("Discard", "Back", "Next", "Submit"…) is dropped, and text inside a button or link (Oracle JET's `oj-button-label`) never labels a control.
Type-ahead fields (a combobox that shows no options when opened, an `aria-autocomplete` list input, a datalist, Lever's `location-input`, a "Start typing..." box, or a react-select list with no options until something is typed, such as Greenhouse's "Location (City)") are filled by typing the saved value, waiting up to 6 s for suggestions (the input's `aria-controls` listbox, react-select's options, Lever's `.dropdown-results`, or nearby options), and clicking the one that equals the value, else the only one with the same words (punctuation, case, accents, and of/the/at/and/in ignored: "University of California, Davis" takes "University of California - Davis"; two such suggestions are never guessed between), else the only one starting with it, or for "City, Region" the only "City, …" suggestion naming the region, where a US state's code and name stand for each other ("Springfield, IL" takes "Springfield, Illinois, United States"; `matchSuggestion`, `packages/browser/src/ats/us-states.ts`); a "City, Region" value with no match is typed again as the city alone and still matched against the whole value; with no such suggestion the typed text is cleared, its list closed, and the field left without focus, and the field is not guessed.
