The repository stays private; a separate public repository mirrors it without candidate or employer details.
`pnpm public:sync -- --public-dir <clone>` (`scripts/public-sync.mjs`) builds each update:

1. `git archive` of `--ref` (default `HEAD`) into a temporary folder, so only tracked files leave; `.env` files are never read.
2. The paths in `PRIVATE_ONLY_PATHS` (`HANDOFF.md`, `triage/`) are dropped, and `PUBLIC-README.md` replaces `README.md` (the private README stays private).
3. The deny-list `data/public-scrub.json` (Git-ignored by `data/*`; another file with `--scrub <file>`) is applied: `replace` rules (`find`, `replace`; literal, whole words unless `"word": false`, a space also matching a line break) swap real company names, employer tenant hosts and slugs, and other literals for neutral examples, longest first. 8-hex run or job ids become `<run id>` anywhere in a `.md` file and inside comments elsewhere. `pnpm-lock.yaml` is never rewritten.
4. A scan fails closed (exit 1, listing file, line, and rule, never the matched secret): any `replace` find still present in any case (unless `"scanCase": true`), any `forbid` pattern (personal identifiers kept only in the deny-list), any remaining run id, and secret shapes (API keys, GitHub, Slack, Google, and Discord tokens, private keys, assigned `*_API_KEY`/`*PASSWORD`/`*TOKEN`/`*SECRET` values) not listed in `allowSecrets` (fake test strings). Without a deny-list nothing is exported.
5. `--verify` runs `pnpm install --frozen-lockfile`, `pnpm typecheck`, and `pnpm test:harness` on a throwaway copy of the export.
6. The export is mirrored into the clone: files that disappeared are deleted, the clone's `.git` and ignored files are untouched, and a dirty clone is refused. The change is committed as the clone's configured author with the message `Sync from private <YYYY-MM-DD>` (no private commit messages or ids) and its diff stat printed. `--push` pushes; `--dry-run` does everything but write the clone and lists what would change; `--out <new dir>` also writes the scrubbed export to a new folder.
