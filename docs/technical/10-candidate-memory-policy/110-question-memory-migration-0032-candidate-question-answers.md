Question memory (migration 0032, `candidate_question_answers`; `packages/db/src/question-answer-repository.ts`) keeps the candidate's own answers to questions outside the fact catalog.
Its key is the question label normalized by `normalizeQuestionText` (`packages/domain/src/question-answer-memory.ts`): NFKD with accents removed, lower case, a trailing `*`, `(optional)`, `(required)`, or `required` dropped, `+` and `#` spelled out so C++ and C# stay apart from C, other punctuation removed, whitespace collapsed; keys match exactly, never fuzzily.
Free text is stored verbatim (at most 200 characters); a select, radio, or checkbox answer stores the chosen option and is reused only where the new field offers exactly one option with the same normalized text, otherwise the field pauses; a checkbox group is answered the same way, and a type-ahead (including a react-select list with no options until typed into) takes the saved answer typed into its suggestions.
Field resolution reads catalog facts first, then question memory (only for questions the catalog does not map), then pauses; a reused answer's decision has basis `question_answer`.
An answer is saved only when the candidate answers a held run's question with remember on (`answerRunPause`, used by `pnpm run:answer` and the run panel), and never for questions naming the posting's company, why/interest/motivation questions, other employer- or role-specific questions (here, this company or role, salary, referral), questions the mapper blocks (protected or attestation) or finds ambiguous, sensitive fields (the EEO role and topics such as birth date, citizenship, criminal history, health), contact details, coursework and course questions (relevant coursework comes only from `pnpm profile:coursework`), acknowledgements and consents, open-ended or essay questions (`isDraftableQuestion`, textareas, voice-draft pauses, answers over 200 characters), uploads, safeguards, and Workday error reports.
Those are used for that run only, and the application timeline records `Answer to "<label>" used for this run only: <reason>.`, never the answer.
A saved answer is never reused on a question that names the posting's company or meets any of those rules.
Saving a question again supersedes the old answer; an identical answer is left as is.
`pnpm profile:answers [--profile real|demo] [--revoke <id or 8-character prefix>]` lists the saved answers and revokes one.
Question memory never feeds the AI fit or voice drafting and is never sent to a model.
Answering a sensitive, protected, attestation, or ambiguous pause now records the answer for that run only instead of refusing it, and `answerRunPause` reports `remembered` only when something was stored.
On continue (`answeredPauseDecision`, shared with Workday's answers), an answered list, radio, checkbox-group, or type-ahead pause is chosen, never typed; a single checkbox is checked for yes and left for no; a number box takes only a number; and an answer that fits no option of the field the page now shows reopens the pause.
