Deterministic mapping handles reviewed paraphrase families and returns a confidence and match method.
It does not interpret an answer or create a fact.
Unknown and ambiguous questions pause; a question asking for both a start and an end date, or a bare "End Date" box, is not mapped.
Per-application attestation questions are flagged for direct handling; the browser planner signs only the whitelisted kinds below, and only under the candidate's setting.
Work authorization also maps "legally eligible to work" and "legally able/permitted to work", except when the question names government, export-control, citizenship, clearance, contract, or project wording.
